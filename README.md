# مبدّل الصوت المحلي — نموذج Android تجريبي

تطبيق Android تجريبي (Android 9 / API 28 فأحدث) يلتقط الميكروفون بعد موافقة المستخدم الصريحة، ويعالج PCM لحظيًا في ذاكرة الجهاز، ثم يشغّله محليًا عبر خرج الصوت المعتاد للهاتف.

## تجربة التطبيق

1. افتح المشروع في Android Studio أو استخدم Gradle مع Android SDK مثبتين.
2. ابنِ وثبّت نسخة debug على جهاز Android 9 أو أحدث.
3. افتح **مبدّل الصوت المحلي** واضغط **بدء الاختبار**؛ لا يطلب التطبيق إذن الميكروفون إلا بعد هذا الضغط.
4. وافق على إذن الميكروفون، ثم استمع إلى الصوت الناتج. أوقفه بزر **إيقاف**.
5. استخدم الإعدادات المسبقة أو المنزلقات لتجربة النغمة، اللون الصوتي، ومستوى الخرج. يُفضّل استخدام سماعات لتقليل الصدى والتغذية الراجعة.

## حدود وظيفية مهمة

- هذا نموذج **داخل التطبيق فقط**: يعالج الصوت الذي يلتقطه بنفسه ويشغّله محليًا للاختبار. لا يبدّل ولا يحقن دخل الميكروفون في WhatsApp أو أي تطبيق آخر، ولا يوفّر معالجة عامة على مستوى النظام.
- لا توجد صلاحية إنترنت في التطبيق، ولا يرفع أو يحفظ تسجيلات. الصوت يمر في الذاكرة أثناء التشغيل فقط؛ يتوقف الالتقاط عند إيقاف الاختبار أو مغادرة الشاشة.
- معالجة pitch تستخدم تأخيرًا متغيرًا برأسين متقاطعي التلاشي، وtimbre مرشح ميل بسيط للترددات العالية. هذه مؤثرات خفيفة لإثبات المسار وليست محوّل صوت احترافيًا؛ قد تظهر آثار صوتية عند التغيير الكبير في النغمة.
- التوجيه، الكمون، ومستوى الصوت الفعلي تعتمد على الجهاز وإصدار Android والخرج المتصل. اختبر بسماعات، وتجنّب رفع الصوت على مكبر الهاتف قرب الميكروفون.
- لا يتضمن هذا المصدر APK مثبتًا أو اختبارًا على جهاز فعلي.

## البناء والاختبار

يتطلب البناء Android SDK Platform 35 وJDK 17 أو أحدث وGradle 8.9 أو إصدارًا متوافقًا مع Android Gradle Plugin 8.7.3.

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

الاختبارات الوحدية في `app/src/test/java/com/cue/micvoicechanger/dsp/RealtimeVoiceProcessorTest.java` تغطي نسبة وتحويل النغمة، المرور المحايد، الصمت، قصّ PCM16، وقياس رفع نغمة اختبارية بأوكتاف.
